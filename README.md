# FitAdapt (codename)

A bilingual (FR/EN), offline-first training companion that turns one person's (or two partners') goals, equipment and daily readiness into a safe, explainable session. "FitAdapt" is a working codename; it is never used publicly before trademark clearance (C13).

This repository starts with the **v2.1 goal pack** and the **governance to take it to market readiness**. There is no product code yet: module M00 is the first `/goal`.
